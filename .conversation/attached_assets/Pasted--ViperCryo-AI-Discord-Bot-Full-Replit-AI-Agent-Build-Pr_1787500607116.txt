# ViperCryo AI Discord Bot — Full Replit AI Agent Build Prompt

Build a production-ready Discord bot for my Discord server **ViperCryo**.

The bot must be written in **Node.js + JavaScript** using **discord.js v14** and must be designed to run reliably on **Replit**.

Do not create a simple demo. Build the complete working application with clean architecture, error handling, persistent database storage, configurable settings, and clear setup instructions.

---

## 1. MAIN PURPOSE

The bot is an AI-powered community assistant for ViperCryo.

It should answer member questions about:

* ViperCryo Discord server
* 6b6t
* Minecraft
* Other games
* General gaming questions
* Technical gaming problems
* Server-related FAQs

The bot must use a combination of:

1. Custom ViperCryo knowledge
2. Game knowledge
3. AI responses
4. Optional web search for current information

The bot must NOT pretend that unknown information is true.

If information is unavailable or uncertain, clearly say that it does not have enough verified information.
